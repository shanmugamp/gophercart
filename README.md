# GopherCart

GopherCart is a production-style commerce microservices platform built
with Go, React, gRPC, PostgreSQL, RabbitMQ, Docker and Kubernetes.

## Services

- API Gateway
- Product Service
- Order Service
- Payment Service
- Notification Service
- Report Service

## Technology

### Backend
- Go
- Gin
- gRPC
- Protocol Buffers
- PostgreSQL
- RabbitMQ

### Frontend
- React
- TypeScript
- Vite
- TanStack Query

### Testing
- Go testing
- Testify
- Testcontainers
- Vitest
- React Testing Library

### Infrastructure
- Docker
- Docker Compose
- Kubernetes

### Observability
- Structured logging
- Prometheus
- Grafana
- OpenTelemetry
